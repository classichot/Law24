# LAW24

**The AI Legal Operating System for Thai Business.** Turn contracts into decisions, actions, approvals, and institutional knowledge.

Not ChatGPT for lawyers. Not generic AI contract review. Two entrances, one shared engine:

| LAW24 Firm | LAW24 Corporate |
| --- | --- |
| Helps local law firms serve more clients profitably | Gives management control over contracts and legal risks |
| White-label Client Review Room | Company-wide legal command center |
| Firm Brain, packaged services, fee proposals | Legal Twin, approvals, outside counsel, board reports |

**Hero:** Contract X-Ray — upload a Thai or English agreement and get a verdict (Accept / Negotiate / Do Not Sign), heatmap, missing clauses, Thai citations, redlines and a management brief.

```bash
npm install
npm run dev
```

Open the URL Next prints (http://localhost:3000, or the next free port).

**Demo:** `preecha@siamdigital.co.th` / `demo1234` (Corporate) or `kanit@7l-advisory.com` / `demo1234` (Firm).

**Live path:** Analyse a Contract → X-Ray → Cockpit / Clause DNA → Twin. Ctrl/⌘K searches. N / P steps the demo bar.
